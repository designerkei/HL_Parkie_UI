사용 규칙 · Usage rules

아이콘만으로 의미를 추측하게 만들지 않고, 상호작용 상태와 운영 상태를 분리합니다.

24px 기본 그리드

기본 크기는 24×24, 선형 아이콘은 2px stroke와 round cap/join을 사용합니다. 16px 이하에서는 별도 소형 자산을 사용합니다.

상호작용 6상태

Default·Hover·Focus·Pressed·Selected/On·Disabled를 분리합니다. Hover와 Pressed는 중립 강조, Focus와 Selected만 브랜드 파랑을 보조 신호로 사용하며 운영 오류 색상과 혼용하지 않습니다.

의미는 텍스트와 함께

버튼에는 접근 가능한 이름을 제공하고, 배터리·통신·경고는 수치나 상태 텍스트를 함께 표시합니다. 색만으로 상태를 전달하지 않습니다.

출처 분리

Parkie Original, Parkie Custom, Adopted를 화면 출처로 구분합니다. 전체 참조 카탈로그는 별도 메뉴에 보존합니다.

무엇을 언제 쓰는가 · Choosing a control

세 컨트롤을 가르는 기준은 적용 시점입니다. 스위치는 누르는 즉시 장비에 전달되고, 체크박스와 라디오는 적용 버튼을 눌러야 반영됩니다. 즉시 적용이 아니라면 스위치를 쓰지 않습니다.

스위치 · Switch

즉시 적용되는 이진 설정입니다. “서비스 시작”처럼 별도 확인이 필요한 명령에는 Button을 사용합니다.

체크박스 · Checkbox

서로 독립적인 항목을 여러 개 고를 때 씁니다. 선택은 적용 버튼을 누른 뒤 반영됩니다.

라디오 · Radio

서로 배타적인 보기 중 하나만 고를 때 씁니다. 항목이 다섯 개를 넘으면 셀렉트로 바꿉니다.

관제 규칙 · Control rules

스위치는 물리 장비에 즉시 작용하므로 일반 웹 설정과 다른 제약을 받습니다.

규칙내용
복구 불가한 명령 금지로봇 전원 차단·비상정지는 스위치로 만들지 않습니다. 되돌릴 수 없는 명령은 Button과 확인 모달을 씁니다.
전송 중 상태명령이 로봇에 전달되는 동안에는 전송 중임을 표시합니다. 누른 즉시 반영된 것처럼 보이면 안 됩니다.
실패 시 롤백명령이 실패하면 스위치를 원래 위치로 되돌리고 이유를 함께 알립니다.
역할별 잠금권한이 없는 역할에서는 비활성으로 두고, 왜 잠겼는지 알 수 있게 합니다.
색만으로 전달 금지On/Off는 위치와 라벨로 구분합니다. 색 하나에 의존하지 않습니다.

복구 가능한 제어

안전 확인

비상모드는 단일 클릭으로 실행하지 않습니다. 전체 정지 범위와 복구 절차를 확인한 뒤 Danger 액션을 수행합니다.
