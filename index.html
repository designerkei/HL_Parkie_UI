00 DESIGN SYSTEM

HL Mando Parking
SMS Design System

로보틱스 주차 관제 대시보드를 위한 다크 UI 시스템. 색·타이포·컴포넌트를 하나의 토큰 언어로 통합해, 상태를 색으로 읽고 3초 안에 판단하는 화면을 만듭니다.

4대 원칙

01
색 = 상태 신호

위계는 크기·굵기로, 의미는 색으로. 색은 장식이 아니라 로봇·차단기·카메라의 상태를 전달하는 신호입니다.

02
다크 Elevation

#131315 위에 흰색 오버레이(dp)를 얹어 깊이를 표현. 저조도 관제실을 전제한 딥 다크 모드입니다.

03
수치 = 모노스페이스

속도·배터리·좌표·번호는 고정폭으로 정렬. 실시간 값이 바뀌어도 자릿수가 흔들리지 않습니다.

04
파괴적 액션 분리

정지·초기화·전체 재부팅은 레드 + 격리(오버플로/모달). 오조작을 구조적으로 막습니다.

Token Architecture

Primitive → Semantic → Component 3계층. Figma Variables와 1:1 매핑되고 코드(CSS 변수/DTCG JSON)로 그대로 떨어집니다.
